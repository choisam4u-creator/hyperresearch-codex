# 품질 평가 (evals)

고정 질문 20개(한국어 10, 영어 10)를 실제 파이프라인(`hprc.pipeline.run`, light tier, 고정 입력 재생)으로 돌리고 최종 보고서를 채점한다. 모델·네트워크는 부르지 않는다.

```bash
HPR_BACKEND=mock python -m evals.run            # 점수 표
HPR_BACKEND=mock python -m evals.run --verbose  # 감점 근거
```

- `cases/*.json`: 질문·합성 출처(`sources`)·기록된 가짜 단계 응답(`responses`: 단계 이름 → 시도별 응답 목록)·의도한 결함(`flaws`). 기록이 없는 단계는 `hprc.mock`을, 비평·다듬기는 "지적 없음"을 쓴다.
- 점수(0~100, 높을수록 좋음, `score.py`)
  - 인용 유효성: 본문 `[Sn]` 중 실제 출처로 풀리는 비율
  - 주장-출처 일치: 인용 문장의 숫자가 모두 인용 원문에 있고 글자 2-gram 절반 이상이 원문에 있는 비율. 수치가 든 원문 문장이 주장과 문맥 낱말을 하나도 공유하지 않거나, 가장 가까운 원문 문장과 증감 방향이 반대면 불일치. 인용 원문에 인과를 긍정하는(유보·부정하지 않은) 문장이 없는데 인과를 단정하거나, 수치가 든 원문 문장과 다른 기간 단위(하루·주·한 달·연간·총계)로 말해도 불일치. 수치가 원문에서 계획·목표·전망 절에만 나오는데 유보 없이 실적처럼 말하거나, 시범·표본 범위 원문 수치를 전역·전체(시 전역·statewide 등) 결과로 말해도 불일치(`(출처 불일치)` 표시가 붙은 문장은 독자에게 경고된 것으로 본다). 수치가 원문에서 추정·잠정치(estimate·preliminary·approximately·추정·추산·잠정·약 등) 명제에만 나오는데 주장이 유보 없이 확정처럼 말해도 불일치 — 이 경우만 `(원문 추정치)`·`(source estimate)` 표시도 경고로 인정한다. 연도·월·일 수치는 이 검사에서 뺀다. 수치를 원문과 다른 기준 연도의 값으로 옮기거나(원문 같은 수치 자리의 연도를 모두 알 때만 — 수치가 든 명제의 연도, 없으면 문장에 연도가 하나뿐일 때 그 연도), 원문이 퍼센트포인트로만 말한 수치를 퍼센트로(또는 반대로) 말해도 불일치(2026-10-06 2회차 추가). 수치는 숫자×자릿수 낱말(천·만·억·조·thousand·million·billion·trillion)로 비교한다: 숫자 글자가 같아도 자릿수 낱말이 원문의 같은 숫자 자리마다 다르면 불일치("420억 원"→"420만 원"), 같은 값을 다르게 쓴 것("1.6 million"↔"1,600,000")은 원문에 있는 수치로 본다(2026-10-07 추가)
  - 잘못 붙은 경고 없음: `(출처 불일치)`·`(원문 추정치)`가 붙은 인용 문장 중 표시를 떼고도 위 주장-출처 일치 대조를 모두 통과하는 문장 비율을 감점(맞는 문장에 경고를 붙여 독자 신뢰를 깎음). 주장-출처 일치는 경고 붙은 문장을 통과로 세므로 경고 남발을 이 항목이 잡는다. 같은 관계 묶음 출처만 함께 인용한 문장은 독립성 경고일 수 있어 세지 않는다. 점수기 대조가 엄격하므로 오표시의 하한이다(2026-10-07 2회차 추가)
  - 중복 출처 없음: 출처 목록의 중복 행과, 같은 관계 묶음(중복 후보) 출처만으로 된 다중 인용을 감점("독립 출처가 아닐 수 있음" 경고가 붙은 것은 제외)
  - 표시 없는 미검증 주장 없음: 답·근거·한계 절에서 인용도 `(판단)`·`(출처 없음)` 표시도 없는 사실 문장 비율을 감점. `(판단)`만 붙었는데 어떤 출처에도 없는 수치를 담거나 출처 수치를 다른 기간 단위로 말하는 문장도 감점
  - 본문 내부 일관성: 인용 없는 문장(`(판단)` 포함)이 같은 대상(문맥 낱말 2개 이상 공유)을 말하는 인용 문장과 증감 방향이 반대인 비율을 감점. 둘 중 하나에 `(출처 불일치)`가 붙어 있으면 경고된 것으로 본다. 또 서로 다른 출처만 인용한 두 문장(대조 통과)이 같은 대상을 반대 방향으로 말하는데 한계 절의 어느 한 줄도 두 출처를 함께 언급하지 않으면 감점(출처끼리 상충을 독자가 모르고 읽음, 2026-10-06 추가). 같은 방향이라도 두 문장이 퍼센트(또는 퍼센트포인트) 수치를 하나씩만 말하고 큰 값이 작은 값의 2배 이상이면 같은 상충으로 본다(2026-10-06 2회차 추가)
  - 보고서 구조: 질문 원문 줄과 답·근거·한계·출처·다음 행동 절이 내용과 함께 있는지
- 실행이 막히면(Blocked) 그 case는 전 항목 0점이다.
- 기준이나 픽스처를 바꾸면 `docs/QUALITY-LOG.md`에 이유를 적는다. 점수를 올리려고 기준을 느슨하게 하지 않는다.
