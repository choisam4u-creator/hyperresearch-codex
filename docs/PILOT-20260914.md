# 고정 입력 실측: 역할별 배정은 이번 2문제에서 토큰을 줄이지 못함

2026-09-14, 구현 `9efb48e`, Codex CLI `0.154.0-alpha.6.2`, macOS. 개발 합성 질문 2개를 각 배정으로 한 번씩 실행했다. 원본 hyperresearch와의 비교나 일반적인 모델 우열 평가가 아니다.

## 결과

**Astra 합계 391,731토큰 → 역할별 배정 416,524토큰: 6.3% 증가.** 시간 합계는 160.9초 → 179.0초로 11.2% 증가했다. 한국어 사실 확인은 3.4% 절감했지만, 영어 조건 비교는 15.1% 증가했다. 영어 역할별 배정에서 비평 지적에 따른 수정 호출이 한 번 추가됐다.

전체 사용량은 **808,255토큰**(입력 797,898 + 출력 10,357), 21회 호출이다. 실패·재시도·미측정 호출은 모두 0회다. 캐시 411,136토큰은 입력의 일부로 합계에 다시 더하지 않았다. 각 실행은 500,000 총 토큰 중단 기준 안에서 완료됐다. 네 실행의 기준 합 2,000,000에 대한 증액·추가 실행은 없었다.

## 통제한 조건

- 같은 Light/lean 크기, 출처 최대 8개, 비평 2개, 인용 표본 5개, 목표 700단어를 사용했다. 실제 고정 출처는 사례별 2개다.
- 한국어에는 facts, 영어에는 comparison 형식을 사용했으며 각 질문의 두 배정에서 동일했다.
- `astra`: 모든 실제 호출 역할을 Astra로 요청. `routed`: 분석·비평 Terra, 작성 Sol, 인용 검사 Astra. 영어 수정 호출은 Terra였다. 검색·다듬기를 실행하지 않아 Luna는 실제 사용하지 않았다.
- 배정별 추론 강도도 저장된 역할표를 따랐다. 따라서 단일 모델 교체만의 인과 실험이 아니라 모델·강도를 포함한 역할 배정 정책 비교다.
- 코드·프롬프트·모델 외 설정·질문·원문·기준 시각의 일치를 evaluator의 `model_routing` 비교로 확인했다. standard와 economy 프리셋 전체를 그대로 비교하지 않았다.
- 고정 원문 replay로 웹 검색·외부 수집 없이 실행했다. 실제 인터넷 리서치 비용은 포함되지 않는다. `verification.semantic`은 기본 OFF를 유지했으므로 새 세부 의미 검사의 비용·정확도를 평가한 실험도 아니다.
- 실행 순서는 한국어 Astra → 한국어 routed → 영어 routed → 영어 Astra. 병렬은 실행 내부 최대 2개, 재시도 0회, 사용량 미측정 시 다음 호출 중단이었다.

## 품질 판정 범위

네 보고서는 자동 표본 검사를 통과했다. 생성 프로세스 밖의 상위 Codex 작업이 보고서와 고정 원문을 대조해, 사례별 필수 핵심 항목 2개씩 총 8개가 보존됐다고 판정했다. 한국어는 샌드박스 조건·정확한 버전 게시일, 영어는 North의 용어집 조건·South의 기본 한국어 및 PDF 제외 조건이다. 판정 파일은 최종 보고서 SHA-256에 결속했다. 별도 유료 심판 리서치 호출은 하지 않았다.

이 검토는 **비블라인드이며 전체 문장 정확도 평가가 아니다.** 두 핵심 항목과 자동 검사 기준으로만 비용 분모를 계산하면 보고서당 Astra 195,865.5토큰, routed 208,262토큰이다. 이를 전체 사실 정확도 100%나 두 배정의 동등 품질 입증으로 읽으면 안 된다.

추가 검토에서 역할별 한국어 보고서의 “배포 시점에는 적용되지 않는다”는 원문 밖 확장으로 읽힐 수 있었다. 역할별 영어 보고서에는 South PDF 제외와 North PDF 미확인을 한 문장에 묶고 S2만 붙인 부분이 있어, North 미확인 근거인 S1도 필요했다. 핵심 항목 점수와 자동 passed만으로 이런 국소 문제를 모두 잡지는 못한다.

## 결정과 다음 실험

30% 토큰 절감 목표는 달성하지 못했다. 기본 프리셋은 바꾸지 않는다. 조건당 1회·합성 질문 2개이므로 통계적 유의성이나 일반적인 우열을 주장하지 않는다. 고정 소량 근거에서도 작성·비평의 반복 문맥과 불필요한 수정 호출이 비용에 영향을 준다는 후속 가설을 얻었다.

다음 후보는 보고서 분량·원문 조건을 그대로 두고 중복 비평 입력과 근거 없는 수정 제안을 줄이는 것이다. 새 코드/프롬프트 후보를 고정한 뒤 반복 실측하고, 그 다음 보류 자료를 평가해야 한다. 추가 모델 실행은 이번 4회 승인에 포함되지 않는다. 기록의 USD 추정은 모델별 실제 요금 검증이 아니므로 비용 비교에 사용하지 않았다.
