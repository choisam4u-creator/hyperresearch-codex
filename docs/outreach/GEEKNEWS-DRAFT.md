# 긱뉴스 소개 글 초안 — 게시 전 검토용

**제목 후보:** Codex CLI로 출처 수집부터 인용 표본 검사까지: hyperresearch-codex 0.4.0

질문 하나를 넣으면 Python이 정찰 검색, 출처 수집, 분석, 초안, 비평, 부분 수정, 인용 표본 검사 순서를 관리하는 공개 도구를 만들었습니다. 모델 호출은 읽기 전용 `codex exec`로 하고, 파일 쓰기와 형식 검사는 Python이 맡습니다. 설치 뒤 `hpr demo`로 모델 호출 없이 결과 형식을 볼 수 있습니다.

사용해 보니 실패 사례도 분명했습니다. 한국어 기술 영상 시장을 조사한 한 실행에서는 출처 8개 중 75%가 일반 YouTube 도움말이었고, 경쟁 채널 자료가 없어 보고서가 `review_required`로 끝났습니다. 인용 표본 5개 중 2개도 미지지였습니다. 이런 한계를 보고서에 그대로 남기고, 출처 후보 다양화 이슈를 열었습니다. 실제 사용 흔적과 함께 고쳐 나가려 합니다.

현재 macOS 실측과 Linux·Windows mock CI를 구분해 공개하고 있습니다. Windows의 실제 Codex 리서치 실행과 외부 사용자 성과는 아직 확인하지 못했습니다. 설치·재현 피드백, 특히 출처 선택과 결과 검토 흐름에 대한 제안을 환영합니다.
