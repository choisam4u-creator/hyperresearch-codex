# 사례: 기술 문제 해결 영상 시장

- **질문:** 공개 자료로 한국어 기술 문제 해결 채널의 유형, 인기 주제, 영상 길이, 수익화 사례를 비교할 수 있는가?
- **실행:** 2026-09-26, light/economy, 7회 모델 호출, 3.7분, 입력 365,056토큰(캐시 176,768), 출력 9,258토큰. 비공개 작업 맥락은 제외하고 측정값과 관찰만 적었다.
- **결과:** 수집 자료 8개로는 실제 채널·영상별 조회수·길이·수익 사례를 비교할 수 없었다. 출처의 75%가 일반 YouTube 도움말이었다. 시장 검증이 끝났다고 보지 않는다.
- **인용 검사:** 실제 인용 출처 5개, 표본 5개 중 미지지 2개, 고위험 지적 4개 미해결. `quality.json`은 `review_required`였고 CLI는 종료 코드 3을 반환했다. 이 실패가 [출처 후보 편중 이슈](https://github.com/choisam4u-creator/hyperresearch-codex/issues/5)의 근거가 됐다.
