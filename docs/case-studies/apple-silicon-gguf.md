# 사례: Apple Silicon 메모리와 GGUF

- **질문:** Apple Silicon 통합 메모리로 로컬 이미지 생성 모델을 돌릴 때의 실제 한계와 GGUF 양자화의 영향은 무엇인가?
- **실행:** 2026-09-13, light/lean, 7회 모델 호출, 4.8분, 입력 604,783토큰(캐시 385,024), 출력 7,018토큰. [공개 원본 보고서](../../examples/report-en-light-lean.md)의 헤더와 당시 측정 기록 기준.
- **결과:** 체크포인트 크기만으로 실행 가능 여부를 정할 수 없고, 전체 파이프라인 메모리·스와핑·백엔드 제약을 함께 봐야 한다고 정리했다. 특정 Mac의 안전한 메모리 수치나 GGUF 속도 향상은 입증하지 못했다.
- **인용 검사:** 출처 8개, 실제 인용 8개, 표본 5개 중 미지지 1개. 린트는 통과했다. 표본 밖 문장은 검사 결과로 보증하지 않는다.
