# 사례: 블로그 JSON-LD와 검색 노출

- **질문:** 블로그에 JSON-LD 구조화 데이터를 넣으면 Google 검색 노출에 어떤 영향이 있고 무엇을 주의해야 하는가?
- **실행:** 2026-09-13, light/lean, 7회 모델 호출, 4.6분, 입력 382,829토큰(캐시 194,048), 출력 6,847토큰. [공개 원본 보고서](../../examples/report-ko-light-lean.md)의 헤더와 당시 측정 기록 기준.
- **결과:** 검색 결과의 제목·이미지·날짜 표시 가능성과 구현 조건을 구분했다. 리치 결과 표시나 검색 순위·클릭률 상승은 보장되지 않으며, 적용 전후 효과의 실측도 없다고 적었다.
- **인용 검사:** 출처 8개 중 5개 인용, 표본 5개 중 미지지 1개, 린트 통과. 출처 도메인이 Google 개발자 문서에 75% 치우쳤다는 경고가 있었다. 표본 밖 사실성과 검색 성과는 미검증이다.
