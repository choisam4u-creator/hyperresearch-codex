# 기존 20회 로그에 근거한 코드 수정

기준 커밋은 `a890162d98d09d5f5f8c049ca4f683211707bdb4`다. 새 실제 리서치 호출 없이 기존 개발 8회·보류 12회의 저장 입력, 주장, 패치 응답을 사용했다. 이전 실측 원본과 품질 판정은 변경하지 않았다.

## 확인한 결함과 수정

1. 분석가는 긴 출처를 읽었지만 작성자는 질문만으로 고른 짧은 발췌를 받아, 분석 주장에 사용된 원문이 빠졌다. 작성 단계에 출처별 주장 질의를 전달하고 원문 문장과 이어지는 조건·예외를 함께 보충한다. 기존 발췌를 교체하지 않으며 짧은 출처의 미사용 문자 예산을 공유한다. 전체 출처 본문 상한은 `출처 수 × draft_note_chars`다. 이 값은 본문 문자 수이고 메타데이터를 포함한 토큰 상한이 아니다. 실제 전달량은 늘 수 있다.
2. 선택 기능인 입력 패킷의 파일별 SHA·바이트 주석을 모델 입력에서 제거했다. 정확한 가상 파일명·원문·종료 경계는 보존하고 감사 해시는 `input_profiles.json`에 남긴다. 패킷 기본값은 계속 OFF다.
3. 일부 수정 항목이 판단 표시를 삭제하면 정상 수정까지 전부 폐기되었다. 이제 해당 항목만 거부하고 독립적인 정상 수정은 적용한다. 전체 변경 비율·미등록 인용·판단 표시 및 다듬기 인용 수 검사는 유지한다. 수정 프롬프트에도 판단 표시 보존을 명시했다.

## 검증과 남은 한계

Astra 독립 코드 재검수, 전체 mock 테스트 400개, 최종 코드·프롬프트와 wheel의 바이트 일치 및 저장소 밖 설치 후 mock 실행이 통과했다. 원격 CI 결과는 해당 커밋의 Actions 기록에서 별도로 확인한다.

회귀 테스트는 조건이 두 문장 이상 이어지거나 내부 분할 경계를 넘어도 함께 전달되는지, 부족한 예산에서 묶음을 생략하는지, 패킷/근거 선택 네 조합, 개별 수정 거부와 전체 안전 검사 유지를 확인한다. 선택은 휴리스틱이며 모든 표현의 조건·반론을 탐지한다는 보장은 없다. 공유 예산도 부족하면 근거가 빠질 수 있다.

**이번 결과로 실제 토큰 절감률, 전체 보고서 품질 향상, 원본 프로젝트 대비 우위를 주장하지 않는다.** 준비 바이트 변화에는 서로 다른 단계·실행 집합이 있고, 수정 프롬프트와 후속 모델 출력도 달라질 수 있어 위 수치를 전체 호출의 절감률로 합산하지 않는다. 이미 모델에 전달됐는데도 잘못 서술한 사례는 이 근거 전달 수정만으로 해결됐다고 볼 수 없다.

후속 실제 비교가 필요하다면 새 예산 승인 뒤 같은 입력의 수정 전/후를 소수 실행하여 근거 누락·조건 누락·최종 사실 오류와 전체 입력+출력 토큰을 함께 확인한다. 이번에 확인한 기존 20건은 독립된 새 평가 자료로 재사용하지 않는다.
