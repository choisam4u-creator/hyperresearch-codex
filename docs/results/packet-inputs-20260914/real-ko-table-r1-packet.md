## 답

구청 별관은 같은 기준에서 피크 전력이 11.2 kW 감소했고 냉방 관련 불만은 1,000 이용시간당 1.1건이었다.[S1]
비교 범위는 설치 전후 각 4주의 평일 오후 1시부터 5시까지이며, 전년 동월이나 연간 사용량을 비교한 결과가 아니다.[S1]
따라서 확인된 성과는 특정 시설·시간대의 관측값과 운영 안정성에 한정되며, 연간 절감액이나 사업 전체의 인과적 효과는 확인할 수 없다.[S1][S2]

### 시스템 운영

성공률은 장비가 수신 확인을 돌려준 명령의 비율로, 재전송 후 성공한 명령도 포함하고 통신 장비 교체 시간은 분모에서 제외했다.[S2]
장애 티켓에는 화면 표시 오류, 실내기 응답 지연, 관리자 계정 잠김이 함께 포함됐으며, 46분은 최초 접수부터 종료까지 걸린 시간의 중앙값이다.[S2]
