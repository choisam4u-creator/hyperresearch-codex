# 질문: 제시된 지역 냉방 시범사업의 성과를 수치·단위·조건과 함께 요약하라.

## 답

2026년 5월부터 8월까지 12개 공공건물에 냉방 제어기를 설치한 시범사업에서, 도서관의 기준 대비 피크 전력은 18.4 kW, 구청 별관은 11.2 kW 감소했다.[S1][S2]
비교 기준은 전년 동월이 아니라 설치 전·후 각 4주의 평일 오후 1시부터 5시까지 계량값이며, 폭염 경보 기간의 자동제어 중단 시간은 비교에서 제외됐다.[S1][S2]
냉방 관련 불만은 도서관 0.7건/1,000 이용시간, 구청 별관 1.1건/1,000 이용시간이었고, 2026년 5월 3일부터 8월 28일까지 명령 성공률 중앙값은 99.2%, 장애 티켓 37건의 중앙 처리 시간은 46분이었다.[S1][S2]
다만 대조군과 보정 결과가 없고 전체 12개 건물의 평균도 제시되지 않아, 도시 전체나 연간 성과는 확인할 수 없다.[S1][S2]

## 근거

시청 에너지과의 2026년 8월 내부 점검 메모는 2026년 5월부터 8월까지 냉방 제어기를 설치한 공공건물 12곳을 대상으로 했으며, 야간 전용 건물과 주말 휴관 시설은 표본에서 제외했다.[S1]

성과 비교에는 같은 건물의 설치 전 4주와 설치 후 4주 중 평일 오후 1시부터 5시까지의 계량기 값이 사용됐고, 전년 동월 사용량은 기준이 아니었다.[S1] 제공된 기록에서는 계량 주기와 결측 처리 절차를 확인할 수 없다.[S2]

도서관의 기준 대비 피크 전력 변화는 -18.4 kW, 구청 별관은 -11.2 kW로, 음수는 피크 전력 감소를 뜻한다.[S1][S2] 표에는 설치 전·후 평균 피크가 아닌 차이만 제시됐으므로, 이 수치만으로 각 시설의 절감률을 계산할 수 없다.[S2]

사용자 불만은 도서관 0.7건/1,000 이용시간, 구청 별관 1.1건/1,000 이용시간이었다.[S1][S2] 이는 냉방 관련으로 확정된 신고를 이용시간으로 표준화한 값이며, 총 민원 건수나 이용자 만족도 점수가 아니다.[S1][S2] 동일 이용자의 반복 연락은 별도 건으로 남을 수 있고 현장에서 구두로 해결된 요청은 빠졌을 수 있다.[S2]

2026년 5월 3일부터 8월 28일까지 제어 명령 성공률 중앙값은 99.2%였다.[S2] 이 성공률은 장비가 수신 확인을 돌려준 비율로, 재전송 후 성공한 명령을 포함하고 통신 장비 교체 시간 2시간은 분모에서 제외했다.[S2] 화면 표시 오류·실내기 응답 지연·관리자 계정 잠김 등을 포함한 장애 티켓은 37건이었고, 최초 접수부터 종료까지 중앙 처리 시간은 46분이었다.[S2] 두 지표는 운영 진단치이며 전력 절감률이나 만족도 점수가 아니다.[S2]

폭염 경보가 발령된 7월 22일부터 24일과 8월 6일부터 8일에는 자동 설정온도 명령을 중단하고 현장 관리자가 수동으로 판단했으며, 해당 시간의 피크 전력은 설치 전후 비교표에서 제외했다.[S2]
