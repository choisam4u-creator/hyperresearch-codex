# 설치 피드백

설치 문제를 제보할 때는 계정 이름, API 키, 토큰, 쿠키, 개인 경로, 연구 원문을 포함하지 말고 최소 정보만 남겨 주세요.

## 먼저 체험하기

설치한 패키지에서 `hpr demo`로 합성 형식 미리보기를 확인할 수 있다. 모델 호출과 네트워크 요청은 없다. 실제 리서치 성공을 검증한 것은 아니다.
기존 실행이 있으면 `hpr feedback RUN_ID` 결과를 직접 확인한 뒤 [제보 안내](FEEDBACK.md)를 따른다. 테스트를 위해 새 유료 실행을 반복할 필요는 없다.

## 제보 양식

- 운영체제 및 Python 버전:
- 설치 방법과 결과(`pip install` 명령에서 비밀값 제거):
- `hpr --help` 결과:
- `hpr doctor` 결과에서 경로·계정·토큰을 제거한 요약:
- `hpr demo` 출력 성공 여부(선택: 소스 체크아웃이 있다면 mock 테스트 결과):
- 첫 결과에 도달했는지:
- 재현 가능한 최소 명령 또는 단계:
- 오류 메시지(민감정보와 fetched page 본문 제거):

이 문서는 자발적 피드백을 위한 양식이다. 외부 연락, 자동 수집, 계정·개인정보 수집, 설치 성공이나 실제 모델 호환성의 보장은 포함하지 않는다.
