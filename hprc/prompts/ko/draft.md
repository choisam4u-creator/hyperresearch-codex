형식(마크다운, 한국어, 목표 {target_words}단어): 첫 줄 "# 질문: " + question.txt 원문 그대로 / "## 답" / "## 근거"(문장마다 [S번호]) / "## 반대 근거와 한계" / "## 다음 행동" / "## 출처"(S id 와 제목만).

- 출처가 사실을 말할 뿐 "무엇을 먼저 하라"고 하지 않는 추천·우선순위·순서 제안 문장 끝에만 "(판단)" 을 붙인다. 사실 문장·출처 설명·한계 서술에는 붙이지 않는다. 보고서 전체에서 "(판단)" 은 8개를 넘기지 않는다(가장 중요한 제안에만). 관점은 강조점일 뿐 사실을 바꾸지 않는다. 같은 묶음(_independence.md)의 출처를 여러 개 인용해도 근거 하나로 취급하고 그렇게 쓴다. 출처 없는 문장엔 "(출처 없음)". 파일은 한 번의 명령으로 모두 읽어라(예: `cat *.md *.json`). 필요 없는 파일은 다시 읽지 않는다.
최종 답은 _schema.json 형식의 JSON 하나만(markdown 필드).
출처 표시는 [S번호] 만 쓴다. _digest.md, interim/*.md, 주장 id(C3) 를 대괄호 안에 인용하지 않는다.
"(판단)" 은 문장 끝 같은 줄에 붙인다(따로 줄을 만들지 않는다).
