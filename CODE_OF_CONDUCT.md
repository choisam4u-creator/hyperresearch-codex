# Code of Conduct

Be kind and specific. Report problems with a run header line, not with guesses about people.

- No harassment, personal attacks or discriminatory language in issues, PRs or discussions.
- Assume good faith; disagree about code and evidence, not about people.
- Do not post fetched third-party page text, credentials or other people's private data in issues.

Maintainers may edit, lock or remove content that breaks these rules and may block repeat offenders. To report a problem privately, open a GitHub security advisory or contact the maintainer through the GitHub profile.
